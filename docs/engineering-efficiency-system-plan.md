# 工程部效率提升系统建设方案（UOS + Windows 跨平台）

## 1. 建设目标（结合现有职责）
- **前期立项与论证闭环**：覆盖方案、论证、可研、初设、审批、归档的全过程。
- **勘察/设计/招投标/合同管理一体化**：形成任务派发—成果验收—评审—合同—付款—变更的全链路追踪。
- **代建项目透明化跟踪**：进度、节点、风险、问题、会议纪要与督办闭环。
- **运行管理日常化**：运维计划、巡检、绩效、资产台账等管理标准化与可追溯。

## 2. 用户规模与角色
- **用户规模**：工程部 4 名员工为核心使用者。
- **角色建议**：管理员、项目经理、工程专员、审阅/审批人（可与 OA 角色映射）。

## 3. 核心功能模块
### 3.1 项目立项与前期管理
- 需求申请、可研、初设、审批、归档流程化。
- 模板库（可研、初设、论证、立项材料）统一标准。
- 版本留痕与变更记录。

### 3.2 勘察/设计/招投标/合同管理
- 勘察/设计任务书、成果验收与评审记录。
- 招投标流程：采购计划、标前审查、评标记录、结果公示。
- 合同台账：合同起草、审批、签订、履约、付款、变更、归档。

### 3.3 代建项目跟踪
- 里程碑计划与甘特图进度。
- 风险/问题台账与整改闭环。
- 会议纪要与督办事项绑定。

### 3.4 运行管理（日常管理）
- 运维计划、巡检任务派发与结果回传。
- 资产设备台账与维保周期提醒。
- 绩效与统计报表。

### 3.5 报表与驾驶舱
- 项目数量、阶段分布、资金执行率、延期统计。
- 维度统计：按年度、项目类型、责任人、单位。

## 4. OA 系统对接方向
- 单点登录（SSO）或账号同步。
- 审批流与 OA 协同：审批节点推送到 OA。
- 待办事项与通知对接。

## 5. 技术架构（适配 UOS + Windows）
- **客户端**：Electron（跨平台）或 Qt（Python/CPP）。
- **服务端**：Java（Spring Boot）或 Python（FastAPI/Django）。
- **数据库**：MySQL（后续可替换国产数据库）。
- **部署方式**：局域网私有部署，支持离线工作缓存与同步。

## 6. 里程碑与实施节奏（可按实际节奏调整）
### 阶段一：需求梳理与流程规范（2-4 周）
- 现有流程梳理、制度整理、模板沉淀。
- 输出《需求规格说明书》《流程图》《模板目录》。

### 阶段二：原型与试点（4-6 周）
- 原型设计与评审确认。
- 试点流程、初始数据导入、关键角色培训。

### 阶段三：开发与上线（8-12 周）
- 核心模块开发、测试、上线。
- 逐步推广与优化。

## 7. 交付物清单
- 《系统建设方案》
- 《需求规格说明书》
- 《原型设计稿》
- 《接口对接方案（OA）》
- 《上线与运维手册》

## 8. 下一步需要确认

2. 审批流程现行制度与模板样例。
3. 数据分类与权限要求。
4. 现有台账数据格式（Excel/文档）。
