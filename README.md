# 现场考核管理大数据平台

一个基于 Web 的现场考核管理系统，用于记录、管理和分析下属现场考核地点的考核情况。

## 功能特性

### 数据仪表盘
- 考核总览统计（考核地点数、完成考核次数、平均得分、待整改问题数）
- 考核得分趋势图（折线图 + 柱状图）
- 各类别合格率饼图
- 各类别扣分统计横向柱状图
- 最近不合格项列表
- 考核地点排名

### 考核地点管理
- 新增、编辑、删除考核地点
- 记录地点名称、地址、联系人、联系电话等信息

### 考核标准管理
- 考核类别管理（环境卫生、安全管理、人员管理、设备管理、服务质量、制度执行等）
- 每个类别下可自定义多个考核标准/要求点
- 为每个标准设置满分值和扣分规则
- 支持启用/停用考核标准

### 考核记录
- 新建考核记录（选择地点、填写检查人员、日期）
- 系统自动加载所有启用的考核标准作为检查项
- 逐项记录扣分、问题描述、整改状态
- 自动计算总得分和总扣分
- 支持草稿/已完成/已审核三种状态
- 批量保存评分结果

### 数据导出
- 单次考核记录导出为 Excel（含完整的考核明细表）
- 考核汇总表导出为 Excel

## 技术架构

| 组件 | 技术 |
|------|------|
| 后端 | Python 3 + Flask |
| 数据库 | SQLite |
| ORM | Flask-SQLAlchemy |
| 前端 UI | Bootstrap 5 + Bootstrap Icons |
| 数据可视化 | ECharts 5 |
| 导出 | openpyxl |

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动应用

```bash
python3 app.py
```

启动后访问 http://localhost:5000 即可使用。

系统首次启动时会自动：
- 创建 SQLite 数据库（`data/assessment.db`）
- 初始化 6 个考核类别和 21 个示例考核标准
- 创建 2 个示例考核地点

### 3. 使用流程

1. **配置考核标准**：进入「考核标准」页面，根据考核合同添加/修改考核类别和标准
2. **添加考核地点**：进入「考核地点」页面，添加需要考核的现场地点
3. **现场考核**：进入「考核记录」页面，点击「新建考核」
   - 选择考核地点、填写检查人员和日期
   - 保存后进入评分页面
   - 逐项记录扣分和问题描述
   - 设置整改状态
   - 点击「批量保存」
4. **查看报表**：返回「数据仪表盘」查看统计分析图表
5. **导出数据**：在考核记录列表中导出 Excel 报表

## 自定义考核标准

系统预置的考核标准仅为示例，您可以根据实际考核合同进行完全自定义：

1. 在「考核标准」页面添加新的考核类别
2. 在每个类别下添加具体的考核要求点
3. 设置每个要求点的满分值和扣分规则
4. 新建考核时，系统会自动加载所有启用的考核标准
